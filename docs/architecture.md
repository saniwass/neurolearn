# NeuroLearn architecture overview

## Stack
- React Native / Expo
- Next.js web app
- FastAPI backend
- PostgreSQL + Redis + Qdrant
- local self-hosted AI with Ollama
- MinIO for storage

## Main modules
- Onboarding
- Personalized Learning Profile
- Study Planner
- Material Ingestion
- Notebook-style knowledge layer
- AI Tutor
- Flashcards and spaced repetition
- Exam preparation mode
- Analytics dashboard

## Goal
Build a premium, adaptive learning product for students and school users in Germany.
